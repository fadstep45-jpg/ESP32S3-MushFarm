1. Первый запуск

sequenceDiagram  
    autonumber  
    actor Пользователь  
    participant ESP32 as Микроконтроллер ESP32  
    participant NVS as Внутренняя память (NVS)  
    participant SD as SD-карта (SPI)  
    participant Сеть as Wi-Fi / NTP  
    participant Web as Web-сервер (Captive Portal)  
    participant MQTT as Брокер WQTT

    Пользователь-\>\>ESP32: Включает новую ферму в розетку  
    activate ESP32  
      
    Note over ESP32: Аппаратная инициализация  
    ESP32-\>\>SD: SD.begin()  
    ESP32-\>\>NVS: Чтение сохраненных настроек сети (SSID/PASS)  
      
    alt Настроек сети нет (или не удалось подключиться)  
        rect rgb(60, 60, 80\)  
            Note over ESP32, Web: Режим первичной настройки (Точка доступа)  
            ESP32-\>\>ESP32: WiFi.softAP("MushFarm\_Setup")  
            ESP32-\>\>Web: Запуск Captive Portal (DNS-перехват)  
              
            Пользователь-\>\>Web: Подключается со смартфона к сети фермы  
            Web--\>\>Пользователь: Всплывающее окно (Страница авторизации)  
            Пользователь-\>\>Web: Вводит домашний Wi-Fi, пароль, токен WQTT  
            Web-\>\>NVS: Сохранение учетных данных  
              
            alt На SD-карте нет config.json  
                Web-\>\>SD: Создание пустого (базового) рецепта  
            end  
              
            Web--\>\>Пользователь: Успешно. Перезагрузка...  
            ESP32-\>\>ESP32: ESP.restart() (Программная перезагрузка)  
        end  
    else Данные сети есть в памяти  
        ESP32-\>\>Сеть: WiFi.begin(сохраненный\_SSID, PASS)  
        Сеть--\>\>ESP32: IP-адрес получен  
        ESP32-\>\>Сеть: configTime() (Синхронизация NTP)  
    end

    ESP32-\>\>MQTT: Подключение к WQTT  
    MQTT--\>\>ESP32: Подключение успешно  
    ESP32-\>\>MQTT: publish("Система в сети. Ожидание команды старта")  
      
    Note over ESP32: Переход в режим ожидания (IDLE)  
    ESP32-\>\>ESP32: state \= IDLE\_MODE  
      
    Пользователь-\>\>MQTT: Отправка команды "СТАРТ"  
    MQTT-\>\>ESP32: Входящий топик: cmd/start  
      
    Note over ESP32: Запуск рабочего цикла (ACTIVE)  
    ESP32-\>\>SD: открыть config.json (рецепт)  
    SD--\>\>ESP32: JSON-строка с параметрами климата  
    ESP32-\>\>ESP32: парсинг\_JSON\_и\_настройка\_ПИД()  
    ESP32-\>\>ESP32: state \= ACTIVE\_MODE  
    ESP32-\>\>MQTT: publish("Климат-контроль запущен")

2. Реагирование на изменения  
   sequenceDiagram  
       autonumber  
       participant ESP32 as Микроконтроллер ESP32  
       participant Рецепт as Активный рецепт (в ОЗУ)  
       participant SCD41 as Датчик SCD41  
       participant MLX as Датчик MLX90614  
       participant Реле as Блок реле / MOSFET  
     
       loop Каждые 5 секунд (внутри loop)  
           Note over ESP32, MLX: 1\. Чтение текущих параметров среды  
           ESP32-\>\>SCD41: readMeasurement()  
           SCD41--\>\>ESP32: t=23°C, h=70%, CO2=1200ppm  
           ESP32-\>\>MLX: readObjectTempC()  
           MLX--\>\>ESP32: t\_субстрата=24°C  
             
           Note over ESP32, Рецепт: 2\. Сравнение с эталоном (Рецептом)  
           ESP32-\>\>Рецепт: получить\_целевые\_значения()  
           Рецепт--\>\>ESP32: target\_t=22°C, target\_h=85%, target\_co2=800ppm  
             
           ESP32-\>\>ESP32: сравнить\_данные\_с\_рецептом(ошибка \= target \- текущее)  
             
           rect rgb(40, 60, 40\)  
               Note over ESP32, Реле: UC-P4: Компенсация саморазогрева субстрата  
               ESP32-\>\>ESP32: вычисление\_ПИД\_Охлаждения(t\_суб, target\_t)  
               ESP32-\>\>ESP32: ШИМ\_вытяжки \= 45%  
               ESP32-\>\>Реле: analogWrite(PIN\_FAN, ШИМ\_вытяжки)  
           end  
     
           alt Конфликт: Влажность \< target\_h И CO2 \> target\_co2 (UC-P2)  
               rect rgb(60, 60, 80\)  
                   Note over ESP32, Реле: Приоритет влажности. Блокировка CO2  
                   ESP32-\>\>ESP32: флаг\_блокировки\_CO2 \= true  
                   ESP32-\>\>ESP32: вычисление\_ПИД\_Влажности(h, target\_h)  
                   ESP32-\>\>ESP32: ШИМ\_увлажнителя \= 100%, ШИМ\_притока \= 20%  
                   ESP32-\>\>Реле: digitalWrite(PIN\_HUM, HIGH)  
                   ESP32-\>\>Реле: analogWrite(PIN\_FAN\_IN, ШИМ\_притока)  
               end  
           else Влажность в норме (h \>= target\_h), но нужен сброс CO2 (UC-P5, P6)  
               rect rgb(80, 60, 60\)  
                   Note over ESP32, Реле: Выдув CO2 и снятие блокировок  
                   ESP32-\>\>ESP32: флаг\_блокировки\_CO2 \= false  
                   ESP32-\>\>ESP32: вычисление\_ПИД\_CO2(CO2, target\_co2)  
                   ESP32-\>\>ESP32: ШИМ\_вытяжки \= 100%  
                   ESP32-\>\>Реле: analogWrite(PIN\_FAN, ШИМ\_вытяжки)  
                     
                   Note over ESP32: После проветривания влажность может упасть (UC-P6)  
                   ESP32-\>\>ESP32: проверка\_падения\_влажности\_ниже\_target\_h()  
               end  
           end  
       end  
     
     
     
     
     
     
     
     
     
     
     
     
     
     
 


3. Работа в сервисном режиме  
   sequenceDiagram  
       autonumber  
       actor Пользователь  
       participant Кнопка as Физическая кнопка  
       participant Сеть as Модуль Wi-Fi  
       participant ESP32 as Микроконтроллер ESP32  
       participant Web as Web-сервер (Captive Portal)  
       participant NVS as Память (NVS/SD)  
       participant Реле as ПИД и Реле  
     
       Note over Пользователь, Сеть: Триггеры запуска Сервисного режима  
         
       alt Вариант А: Потеря/Отсутствие Wi-Fi  
           ESP32-\>\>Сеть: WiFi.begin(SSID, PASS)  
           Сеть--\>\>ESP32: WL\_CONNECT\_FAILED (Тайм-аут)  
       else Вариант Б: Принудительный ручной запуск  
           Пользователь-\>\>Кнопка: Удержание 3 секунды  
           Кнопка--\>\>ESP32: Аппаратное прерывание (Interrupt)  
       end  
     
       Note over ESP32, Web: Переход в Сервисный Режим  
       ESP32-\>\>ESP32: state \= SETUP\_MODE  
       ESP32-\>\>Сеть: WiFi.mode(WIFI\_AP\_STA)  
       ESP32-\>\>Сеть: WiFi.softAP("MushFarm\_Setup")  
       ESP32-\>\>Web: server.begin() (Запуск портала настройки)  
     
       par Фоновое поддержание климата (если ферма уже работала)  
           loop Работа ПИД в фоне  
               ESP32-\>\>ESP32: чтение\_датчиков\_и\_расчет\_ПИД()  
               ESP32-\>\>Реле: удержание\_заданных\_параметров()  
           end  
       and Настройка системы пользователем  
           Пользователь-\>\>Сеть: Подключается со смартфона к "MushFarm\_Setup"  
           Сеть--\>\>Пользователь: Всплывающее окно авторизации (Captive Portal)  
           Пользователь-\>\>Web: HTTP POST: Вводит новые SSID/PASS и/или Рецепт  
           Web-\>\>ESP32: валидация\_введенных\_данных()  
             
           alt Данные корректны  
               ESP32-\>\>NVS: сохранить\_учетные\_данные\_и\_config()  
               NVS--\>\>ESP32: Запись успешна  
               Web--\>\>Пользователь: HTTP 200 OK (Настройки применены)  
                 
               Note over ESP32, Сеть: Выход из Сервисного режима  
               ESP32-\>\>Web: server.end()  
               ESP32-\>\>Сеть: WiFi.softAPdisconnect()  
               ESP32-\>\>Сеть: WiFi.begin(новый\_SSID, новый\_PASS)  
               ESP32-\>\>ESP32: state \= ACTIVE\_MODE (Возврат к штатной работе)  
           else Ошибка валидации  
               Web--\>\>Пользователь: HTTP 400 Bad Request  
           end  
       end  
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
     
4. Аварии и самовосстановление  
   sequenceDiagram  
       autonumber  
       participant ESP32 as Микроконтроллер ESP32  
       participant XKC as Датчик воды (XKC-Y25)  
       participant Датчики as Климат (SCD41, MLX)  
       participant Таймер as Системный таймер  
       participant Реле as Блок реле / ШИМ  
       participant MQTT as Брокер WQTT  
     
       Note over ESP32, MQTT: БЛОК 1: Авария уровня воды (Без проверки динамики)  
       ESP32-\>\>XKC: Опрос уровня воды (digitalRead)  
         
       alt Вода ниже уровня датчика (LOW)  
           XKC--\>\>ESP32: LOW  
           ESP32-\>\>Таймер: Запуск таймера "Сухой ход" (например, 60 мин)  
           ESP32-\>\>MQTT: Alert: "Внимание\! Низкий уровень воды."  
             
           alt Таймер истек, вода НЕ долита  
               Таймер--\>\>ESP32: Тайм-аут сухого хода  
               ESP32-\>\>Реле: Принудительное ОТКЛЮЧЕНИЕ увлажнителя  
               ESP32-\>\>ESP32: Блокировка работы ПИД влажности  
               ESP32-\>\>MQTT: Alert: "Сухой ход\! Увлажнитель отключен для защиты."  
           end  
       end  
         
       opt Самовосстановление по воде (долив)  
           XKC--\>\>ESP32: HIGH (Вода появилась)  
           ESP32-\>\>ESP32: Сброс таймеров и блокировок  
           ESP32-\>\>Реле: Разрешение работы увлажнителя  
           ESP32-\>\>MQTT: Уведомление: "Вода в норме, работа ПИД влажности восстановлена."  
       end  
     
       Note over ESP32, MQTT: БЛОК 2: Климатические аварии (С окном наблюдения)  
       ESP32-\>\>Датчики: Опрос параметров (t°, h, CO2)  
       Датчики--\>\>ESP32: Целевые показатели не достигнуты  
         
       alt ПИД работает на 100% дольше лимита времени  
           Note over ESP32: Возникновение подозрения на аварию  
           ESP32-\>\>ESP32: Запоминание текущих показаний (Фиксация)  
           ESP32-\>\>MQTT: Alert: "Сбой климата. Даю системе время на реакцию..."  
             
           ESP32-\>\>Таймер: Запуск таймера наблюдения (например, 15 мин)  
           Note over ESP32, Реле: Реле продолжает работать на 100%. Ждем изменений.  
             
           loop Окно наблюдения  
               ESP32-\>\>Датчики: Регулярный сбор текущих данных  
           end  
             
           Таймер--\>\>ESP32: Время наблюдения истекло  
           ESP32-\>\>ESP32: Сравнение: Текущие значения vs Зафиксированные  
             
           Note over ESP32, MQTT: Принятие финального решения  
           alt Изменения ЕСТЬ (Положительная динамика)  
               Note over ESP32: Процесс идет, оборудование исправно  
               ESP32-\>\>ESP32: Сброс статуса Аварии (Самовосстановление)  
               ESP32-\>\>MQTT: Уведомление: "Динамика положительная. Система справляется."  
           else Изменений НЕТ (или стало хуже)  
               Note over ESP32, Реле: Физическая поломка (сгорел кулер, порван патрубок)  
               ESP32-\>\>Реле: Принудительное ОТКЛЮЧЕНИЕ проблемного узла  
               ESP32-\>\>ESP32: Установка флага КРИТИЧЕСКОЙ БЛОКИРОВКИ узла  
               ESP32-\>\>ESP32: Прекращение попыток восстановления  
               ESP32-\>\>MQTT: КРИТИЧНО: "Изменений нет\! Узел отключен для предотвращения поломки."  
           end  
       end  
     
     
     
     
     
     
     
     
     
     
     
     
     
 


5. Отказ датчиков и памяти

sequenceDiagram  
    autonumber  
    participant ESP32 as Микроконтроллер ESP32  
    participant I2C as Шина I2C (Датчики)  
    participant SD as SD-карта  
    participant Сеть as Wi-Fi Модуль  
    participant MQTT as Брокер WQTT

    Note over ESP32, MQTT: Диагностика климатических сенсоров (Шина I2C)

    ESP32-\>\>I2C: Запрос данных SCD41 (Воздух)  
    alt NACK (Нет ответа от датчика \- UC-N5)  
        I2C--\>\>ESP32: Ошибка связи  
        ESP32-\>\>ESP32: Программный сброс шины I2C и повтор  
        alt Повторная ошибка  
            ESP32-\>\>ESP32: Остановка ПИД Влажности и CO2  
              
            opt Если SD-карта доступна  
                ESP32-\>\>SD: Запись лога: "ERROR\_N5: Отказ SCD41"  
            end  
            opt Если Wi-Fi подключен  
                ESP32-\>\>MQTT: Alert: "КРИТИЧНО: Отказ датчика воздуха SCD41\! ПИД остановлен."  
            end  
        end  
    end

    ESP32-\>\>I2C: Запрос данных MLX90614 (Субстрат)  
    alt NACK (Нет ответа от пирометра \- UC-N6)  
        I2C--\>\>ESP32: Ошибка связи  
        ESP32-\>\>ESP32: Переключение ПИД Охлаждения на датчик SCD41  
          
        opt Если SD-карта доступна  
            ESP32-\>\>SD: Запись лога: "ERROR\_N6: Отказ MLX90614. Резервный режим"  
        end  
        opt Если Wi-Fi подключен  
            ESP32-\>\>MQTT: Alert: "Сбой пирометра\! Переход на резервный контроль температуры."  
        end  
    end

    Note over ESP32, MQTT: Диагностика связи (UC-N4)  
    ESP32-\>\>Сеть: Проверка статуса (WiFi.status)  
    alt Нет связи (WL\_DISCONNECTED)  
        Сеть--\>\>ESP32: Отключено  
        ESP32-\>\>ESP32: Переход на аппаратный таймер (RTC ESP32)  
        ESP32-\>\>ESP32: Накопление телеметрии в ОЗУ  
          
        opt Если SD-карта доступна  
            ESP32-\>\>SD: Запись лога: "WARN\_N4: Потеря Wi-Fi. Переход в автономный режим"  
        end  
        Note over ESP32, MQTT: Оповещение пользователя невозможно до появления сети  
    end

    Note over ESP32, MQTT: Диагностика памяти (UC-N1)  
    ESP32-\>\>SD: Попытка записи буфера телеметрии/логов  
    alt Ошибка SPI / Карты нет  
        SD--\>\>ESP32: Ошибка записи  
        ESP32-\>\>ESP32: Попытка перемонтировать SD (3 раза)  
        alt Попытки исчерпаны  
            ESP32-\>\>ESP32: state \= CRITICAL\_HALT (Полная остановка фермы)  
              
            opt Если Wi-Fi подключен  
                ESP32-\>\>MQTT: Alert: "КРИТИЧЕСКИЙ СБОЙ: Отказ SD-карты. Система экстренно остановлена\!"  
            end  
        end  
    end
