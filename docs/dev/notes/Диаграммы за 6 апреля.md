1\. Глобальная инициализация и «Безопасный старт»

sequenceDiagram  
    autonumber  
    participant ESP32 as ESP32 (Main Loop)  
    participant NVS as Память NVS  
    participant WiFi as Модуль WiFi  
    participant MQTT as Брокер MQTT  
    participant UI as Пользователь (AP/Web)  
    participant SD as SD-карта  
    participant Sensors as Датчики  
    participant NTP as Время (NTP)

    Note over ESP32: ВКЛЮЧЕНИЕ ПИТАНИЯ  
    ESP32-\>\>NVS: Поиск данных (SSID, Pass, MQTT)  
      
    alt Данных в NVS НЕТ  
        ESP32-\>\>ESP32: Запуск Точки Доступа (AP)  
        Note over UI: Ввод новых данных  
        UI-\>\>ESP32: Передача настроек  
        ESP32-\>\>NVS: Сохранение данных  
    end

    Note over ESP32: ЭТАП: Подключение к WiFi  
    loop Попытки WiFi (max 3\)  
        ESP32-\>\>WiFi: Попытка подключения  
        WiFi--\>\>ESP32: Результат (Успех/Отказ)  
        break Если Успех  
            Note over ESP32: WiFi OK  
        end  
    end

    alt WiFi НЕ подключен (после 3 попыток)  
        ESP32-\>\>ESP32: Запуск Точки Доступа (AP)  
        UI-\>\>ESP32: Ввод НОВОЙ сети/пароля  
        ESP32-\>\>NVS: Обновление данных  
        Note over ESP32: Возврат к попыткам WiFi  
    else WiFi OK  
        Note over ESP32: ЭТАП: Подключение к MQTT  
        ESP32-\>\>MQTT: Попытка подключения  
        alt MQTT Ошибка  
            ESP32-\>\>ESP32: Запуск Точки Доступа (AP)  
            UI-\>\>ESP32: Ввод новых данных MQTT  
            ESP32-\>\>NVS: Обновление данных  
            Note over ESP32: Возврат к попытке MQTT  
        else MQTT OK  
            ESP32-\>\>ESP32: Выключение AP (скрыть сеть)  
        end  
    end

    Note over ESP32: СЕТЬ ГOTOВА. ПРОВЕРКА SD.  
      
    loop Попытки монтирования SD (max 3\)  
        ESP32-\>\>SD: Попытка mount()  
    end  
      
    alt SD ошибка (после 3 попыток)  
        ESP32-\>\>MQTT: Публикация \[ERROR\]: "SD Card Mount Failed"  
        ESP32-\>\>ESP32: ФАТАЛЬНАЯ ОШИБКА: "Авария SD"  
    else SD готова  
        Note over ESP32: РЕЖИМ ОЖИДАНИЯ (IDLE)  
        UI-\>\>ESP32: Команда "Начать цикл"  
          
        Note over ESP32: ПРЕДСТАРТОВЫЙ ЧЕК-ЛИСТ  
        ESP32-\>\>SD: Сканирование папки /recipes/  
          
        alt Рецептов НЕТ  
            ESP32-\>\>MQTT: Публикация \[WARNING\]: "No recipes found. Please add a recipe."  
            ESP32--\>\>UI: "Ошибка: Добавьте хотя бы один рецепт"  
            Note over ESP32: Возврат в режим IDLE  
        else Рецепты ЕСТЬ  
            ESP32-\>\>Sensors: Опрос всех датчиков (I2C)  
            alt Сбой датчика  
                ESP32-\>\>MQTT: Публикация \[ERROR\]: "Sensor \[Name\] Timeout"  
                ESP32--\>\>UI: "Ошибка датчика. Старт отменен."  
            else Все OK  
                ESP32-\>\>NTP: Синхронизация времени  
                ESP32-\>\>SD: Создание current\_recept.json  
                ESP32-\>\>ESP32: Статус ACTIVE\_RUN  
            end  
        end  
    end

2\. Основной цикл управления 

sequenceDiagram  
    autonumber  
    participant MainLoop as loop() (millis)  
    participant RAM as ОЗУ (Кэш рецепта)  
    participant Sensors as Датчики (I2C)  
    participant PID as Математика ПИД  
    participant MOSFET as MOSFET (ШИМ)  
    participant MQTT as Брокер MQTT  
    participant Log as ОЗУ Буфер (Логи)

    loop Каждые 2 секунды  
        MainLoop-\>\>Sensors: Чтение текущих значений (t, h, CO2)  
        Sensors--\>\>MainLoop: Текущие данные  
          
        alt Ошибка чтения I2C (Обрыв провода / NaN)  
            MainLoop-\>\>MOSFET: Экстренное обесточивание (ШИМ \= 0\)  
            MainLoop-\>\>MQTT: Публикация \[CRITICAL ERROR\]: Потеря связи с I2C датчиком\!  
            MainLoop-\>\>Log: Запись лога: \[CRITICAL ERROR\] Обрыв провода  
        else Данные валидны  
            MainLoop-\>\>RAM: Запрос уставки (Target) и Гистерезиса (Hyst)  
            RAM--\>\>MainLoop: Возврат значений  
              
            Note over MainLoop: Математическое условие:\<br/\>Отклонение \> Гистерезис?  
              
            alt Выход за пределы гистерезиса (Активация)  
                MainLoop-\>\>PID: Передача ошибки для расчета (Target \- current\_val)  
                PID--\>\>MainLoop: Требуемая мощность (ШИМ 0-255)  
                MainLoop-\>\>MOSFET: Включение нагрузки (ledcWrite)  
                MainLoop-\>\>Log: Запись события отклонения в буфер  
            else Значения в пределах нормы (Ожидание)  
                MainLoop-\>\>MOSFET: Отключение нагрузки (ШИМ \= 0\)  
                Note over MainLoop: ПИД-регулятор в состоянии покоя  
            end  
        end  
    end

3\. Климатический арбитраж и «Горячая замена»

sequenceDiagram  
    autonumber  
    participant UI as Пользователь (MQTT/Web)  
    participant Main as ESP32 Logic  
    participant SD as SD-карта  
    participant Sensors as Датчики CO2  
    participant MOSFET as MOSFET (Вытяжка/Увлажн)

    alt Изменение рецепта на лету (UC-P3)  
        UI-\>\>Main: Новая уставка (например, h=90%)  
        Main-\>\>Main: Флаг PAUSE\_CLIMATE \= true  
        Main-\>\>SD: Перезапись current\_recept.json  
        Main-\>\>Main: Обновление целевых переменных в ОЗУ  
        Main-\>\>Main: Флаг PAUSE\_CLIMATE \= false  
    end

    alt Конфликт Влажность vs CO2 (UC-P4)  
        Note over Main: Требуется вытяжка (CO2) И увлажнение (h)  
        Main-\>\>MOSFET: Вытяжка \= 0 (Блокировка)  
        Main-\>\>MOSFET: Увлажнитель \= 100%  
          
        loop Ожидание влажности  
            Main-\>\>Sensors: Мониторинг CO2  
            alt CO2 \> Критический порог удушья (напр. 4000ppm)  
                Note over Main: Угроза гибели\! Harvest-First арбитраж.  
                Main-\>\>MOSFET: Увлажнитель \= 0 (Пауза)  
                Main-\>\>MOSFET: Вытяжка \= 100% (Экстренный сброс 1 мин)  
            end  
        end  
          
        Note over Main: Цель по влажности достигнута  
        Main-\>\>MOSFET: Снятие блокировки вытяжки  
    end

4\. Двухступенчатая защита воды

sequenceDiagram  
    autonumber  
    participant Water as Датчик Воды (High Level)  
    participant ESP as ESP32 (Timer)  
    participant UI as Оповещение  
    participant MOSFET as MOSFET (Увлажнитель)  
    participant SCD as Датчик SCD41 (h)

    Water-\>\>ESP: Сигнал LOW (Вода ниже датчика)  
    ESP-\>\>UI: \[WARNING\] Низкий уровень. Резерв 60 мин.  
    Note over ESP: ПИД работает штатно (100% доверие)  
      
    alt Вода долита до истечения таймера  
        Water-\>\>ESP: Сигнал HIGH  
        ESP-\>\>UI: \[INFO\] Бак пополнен. Таймер сброшен.  
        Note over ESP: Возврат в штатный режим  
    else Прошло 60 минут (Таймер истек)  
        ESP-\>\>UI: \[WARNING\] Резерв исчерпан. Режим выживания.  
          
        loop Слепой режим (Импульсы)  
            ESP-\>\>MOSFET: ВКЛ (15 сек)  
            ESP-\>\>MOSFET: ВЫКЛ (Пауза 3 мин)  
            Note over ESP: Ожидание распределения тумана  
            ESP-\>\>SCD: Проверка градиента влажности  
            alt Влажность растет (Датчик врет)  
                Note over ESP: Сброс счетчика ошибок.\<br/\>Продолжаем импульсный режим.  
            else Влажность не растет  
                Note over ESP: Ошибка 1, 2, 3...  
                break 3 ошибки подряд  
                    ESP-\>\>MOSFET: ВЫКЛ (Блокировка порта)  
                    ESP-\>\>UI: \[CRITICAL ERROR\] Бак пуст. Увлажнитель изолирован.  
                end  
            end  
        end  
    end

5\. Интеллектуальная диагностика

sequenceDiagram  
    autonumber  
    participant PID as ПИД-регулятор  
    participant Sensors as Датчики  
    participant Logic as Анализ трендов  
    participant MOSFET as MOSFET  
    participant UI as Оповещение / SD-карта

    Sensors-\>\>Logic: Параметр выше нормы (Крит. порог)  
    Logic-\>\>UI: \[WARNING\] Климат не в норме (MQTT \+ Лог).  
      
    PID-\>\>MOSFET: Расчетная Мощность (ШИМ)  
      
    alt ШИМ достигает 100% (Максимум)  
        Note over Logic: Старт таймера анализа градиента (10 мин)  
        loop Сбор градиента  
            Sensors-\>\>Logic: Текущее значение  
            Logic-\>\>Logic: Вычисление производной de/dt  
        end  
          
        alt Градиент отрицательный (улучшение)  
            Logic-\>\>UI: \[INFO\] Система справляется. Тренд положительный.  
        else Градиент \>= 0 (нет улучшений)  
            Logic-\>\>MOSFET: Принудительное ВЫКЛ (Изоляция порта)  
            Logic-\>\>UI: \[ERROR\] Аппаратный сбой оборудования. Узел остановлен.  
        end  
    end

6\. Кросс-валидация температур (Термогенез)

sequenceDiagram  
    autonumber  
    participant SCD as Датчик Воздуха (h, CO2)  
    participant MLX as Датчик Субстрата (t)  
    participant Logic as Кросс-Логика  
    participant UI as Оповещение (MQTT)  
    participant SD as SD-карта (ОЗУ Буфер)

    alt Проверка на термогенез  
        MLX-\>\>Logic: t\_субстрата  
        SCD-\>\>Logic: t\_воздуха  
        Note over Logic: Дельта \= abs(t\_суб \- t\_возд)  
        alt Дельта \> Нормы (Инкубация 8C / Плод. 3C)  
            Logic-\>\>Logic: Ошибка пирометра. Переход на SCD41.  
            Logic-\>\>UI: \[ERROR\] Аномалия MLX90614. Аварийный переход на SCD41.  
            Logic-\>\>SD: Запись лога: \[ERROR\] Отказ ИК-пирометра.  
        end  
    end
